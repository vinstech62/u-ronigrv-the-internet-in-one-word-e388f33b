**quicksand** — the entire internet, in one word.

You step in to look up one thing and sink for three hours. It is not one app, one site, or one mood: whatever you came for — a recipe, a fact, a five-minute break — the whole thing pulls you under the same way, and you surface wondering where the afternoon went.

## Run it

```sh
python3 main.py
```

Writes exactly one word to `/output/entry.txt`. Deterministic: every run produces the same file, byte for byte.
